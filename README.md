# George Bergh – Portfolio

Single-file portfolio website for George Bergh, graphic designer.

- `index.html` – the whole site (HTML, CSS and JavaScript in one file, images embedded).
- Open `index.html` in a browser to view it.
- Edit it in any code editor, commit, and push to update.

To host free: enable **GitHub Pages** (Settings → Pages → deploy from `main` branch, root).
